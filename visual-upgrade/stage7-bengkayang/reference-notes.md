# Referensi dan batas representasi

Acuan utama: brief pengguna Prompt 6D — Bengkayang, Waterfall Adventure, hutan hujan tropis, perbukitan, sungai berbatu, jembatan, Riam Merasap sebagai inspirasi visual utama. Tidak ada foto khusus Riam Merasap yang dilampirkan.

Akses `https://id.wikipedia.org/wiki/Riam_Merasap` dicoba pada 21 Oktober 2026 (zona pengguna Asia/Bangkok): proxy menolak CONNECT dengan HTTP 403. Tidak mengambil gambar web atau aset berlisensi. Siluet air terjun lebar pada tebing dipakai sebagai arah desain umum; detail/ukuran/denah/geologi belum diverifikasi dari foto.

Arena bukan rekonstruksi geografis/ekologis atau representasi akurat ukuran landmark. Sungai, plateau, dek pandang, jembatan, tanaman dan rute adalah komposisi stylized orisinal/fiktif untuk game, bukan gambaran balap nyata di kawasan wisata atau alam. Seluruh thumbnail dan screenshot adalah render game sebenarnya, bukan ilustrasi generatif.
