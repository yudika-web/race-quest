HTML distribusi **19.539.444 byte**, dengan semua aset tertanam, tanpa CDN. Kontrol, bank soal, pause/kuis, buff, AI, stage, Grand Prix, progres, ghost, suara dan aturan game tetap menggunakan kode yang sama. Garasi mempertahankan drag, zoom, reset dan rotasi otomatis, dengan ekspresi ringan untuk tiga karakter baru.

`index.html` tidak diganti. Tidak ada merge ke `main` atau deployment GitHub Pages. Riwayat [rilis Kucing blocky](visual-upgrade/cat-blocky/README.md) dan [HTML Kucing sebelumnya](visual-upgrade/race-quest-visual-upgrade.html) tetap tersedia sebagai baseline.
